Assessment design

Make misconceptions visible

An error-analysis task asks learners to locate the first unsupported step, repair the mathematics, and verify their correction.

Available to inspect: REM student page and matching annotated key

Context
Independent REM assessment and practice materials. District employment work is separate from this public sample.
Audience
Algebra 1 learners connecting tables, written descriptions, and absolute-value graphs.
My contribution
Task design, misconception selection, student response structure, and teacher interpretation support.
Evidence boundary
The material demonstrates alignment and diagnostic intent. Item-bank totals, district usage, and learner results are not established by this sample.

Inspect the assessment pair

“Graph absolute value functions from tables and written descriptions,” page 3 of 8. The graphs intentionally depict errors for the learner to diagnose; the teacher annotations identify the repair.

From objective to evidence

This map explains three cases visible in the sample above. It is a portfolio analysis of the materials, not a record of student responses.

Objective: graph absolute value functions from tables and written descriptions.
Task and evidenceMisconceptionFeedback and verification
Case 1: table points (1, −3), (3, −5), and (5, −3)Reversing the opening direction. The flawed graph opens down.Keep vertex (3, −5) and open up. Check that both outer points are 2 units above the vertex.
Case 3: table minimum at (1, −5)Plotting every output one unit too high.Use the original table outputs. Verify the vertex at (1, −5), then check (−1, −3).
Case 4: peak at (3, 5), dropping 2 cm per metre awayShifting every input one unit right.Keep the stated x-values. Verify (3, 5), (1, 1), and (5, 1).

What the design is trying to reveal

  • Locate the first invalid stepA correct final answer can hide a weak procedure. Naming the first unsupported move gives the teacher more specific information.
  • Require a repair and a checkThe learner must produce a corrected representation and test it against the source. Recognizing that a graph looks wrong is only the starting point.
  • Use several representationsTables and written descriptions require different reading decisions. The shared response routine helps focus attention on the mathematical evidence.

How I would evaluate the sample

Review whether learners identify the first invalid step, give a mathematically valid repair, and verify it with an original value. Compare these dimensions separately, then revise any prompt that repeatedly causes a reading error unrelated to the target skill. A dated revision record and learner-response study would extend the evidence shown here.
