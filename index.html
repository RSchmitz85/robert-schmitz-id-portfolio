My process / ADDIE

A clear purpose.
A thoughtful path to learning.

I use ADDIE to connect the learner’s need to the finished experience. Each phase gives me a question to answer—and evidence to carry into the next decision.

  1. 01

    Analyze

    Identify the learners, the performance gap, and the conditions for success.

    See this phase →
  2. 02

    Design

    Align objectives, practice, feedback, and assessment before building the lesson.

    See this phase →
  3. 03

    Develop

    Build the experience, its visual language, and the support materials that make it usable.

    See this phase →
  4. 04

    Implement

    Prepare the delivery, test the setup, and equip the person facilitating the learning.

    See this phase →
  5. 05

    Evaluate

    Review the work, gather evidence, and use what it reveals to guide revision.

    See this phase →

Revision runs through all five phases. A finding in evaluation can send me back to the objective, the practice, or the delivery.

I like learning experiences with personality: a character to follow, a problem to investigate, a reason to try again. Every visual choice still needs to serve the task.

I start with what learners need to do, build practice around it, and write feedback for the places they’re likely to get stuck. My work includes a published Storyline Web course, HTML interactions, storyboards, and Canvas/QTI assessment packages.
