Unit 2 self-check · Equations and mathematical arguments

This is a self-check. Write your reasoning before choosing an answer. Feedback appears after checking; this public preview does not save grades.

1. Solve 6x − 5 = 25.

Add 5 to get 6x = 30, then divide by 6.

2. Solve 4(x + 1) = 2x + 18.

4x + 4 = 2x + 18 gives 2x = 14, so x = 7.

3. What is the solution set of 5x + 2 = 5x + 8?

Subtracting 5x gives the false statement 2 = 8.

4. Solve C = 2πr for r.

Divide both sides by the nonzero constant 2π.

5. A learner gets x = 3 for 2x + 9 = 17. Which check correctly evaluates this?

A solution must make the original equality true; 15 does not equal 17.
