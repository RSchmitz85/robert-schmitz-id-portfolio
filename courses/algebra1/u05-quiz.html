Unit 5 self-check · Linear relationships and models

This is a self-check. Write your reasoning before choosing an answer. Feedback appears after checking; this public preview does not save grades.

1. Slope through (1, 8) and (4, 2)?

(2 − 8)/(4 − 1) = −6/3 = −2.

2. What is the y-intercept of y = −3x + 7?

Set x = 0 to get y = 7.

3. Write the line with slope −2 through (3, 1).

1 = −2(3) + b gives b = 7.

4. A tank has V(t) = 45 − 5t liters. When is it empty?

Set 0 = 45 − 5t and solve t = 9.

5. Which point is on y = x/2 − 4?

At x = 4 the output is 2 − 4 = −2.
