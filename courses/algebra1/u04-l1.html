4.1 · Recognize a function

Learning target

Determine whether every input has exactly one output.

Think about the idea

A function assigns exactly one output to each input in its domain. Different inputs may share an output. A repeated input with different outputs breaks the rule. On a graph, a vertical line meeting the graph more than once reveals such a repeated input.

Worked example

Is {(1, 4), (2, 4), (3, 7)} a function?

  1. List the inputs: 1, 2, 3.
  2. Each input appears with exactly one output.
  3. It is a function. Two inputs sharing output 4 is allowed.

Spot and repair an error

A learner rejects a function because two x values have the same y value.

Before revealing the explanation, identify the first incorrect step and propose a repair.

Compare your repair

The rule restricts outputs per input, not inputs per output.

Your turn

Work each question independently. Include a method or explanation, then compare your reasoning.

Practice 1

Is {(0, 2), (0, 5), (1, 3)} a function?

Check the reasoning

No. Input 0 has two different outputs, 2 and 5.

Practice 2

Is y = 3 a function of x?

Check the reasoning

Yes. Every real x has the single output 3.

Practice 3

Why is a circle not generally a function of x?

Check the reasoning

Some vertical lines cross it twice, giving two y values for the same x.

Reflect before moving on

Explain one decision you made and how you checked it. If your answer changed after checking, record the original error and your corrected reasoning.
