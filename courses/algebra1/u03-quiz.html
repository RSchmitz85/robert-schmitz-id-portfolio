Unit 3 self-check · Inequalities and constraints

This is a self-check. Write your reasoning before choosing an answer. Feedback appears after checking; this public preview does not save grades.

1. Which values satisfy x > −1?

Both 0 and 2 are greater than −1; the boundary itself is excluded.

2. Solve −2x + 3 ≥ 11.

Subtract 3, then divide by −2 and reverse the inequality.

3. Solve 1 ≤ x + 4 < 9.

Subtract 4 from all three parts, keeping each boundary type.

4. A $35 budget includes a $5 fee and $8 per item. Maximum whole items?

5 + 8n ≤ 35 gives n ≤ 3.75. Four items would cost $37.

5. Which describes x ≤ 2 or x > 6?

Or combines both regions; 2 is included, 6 is excluded.
