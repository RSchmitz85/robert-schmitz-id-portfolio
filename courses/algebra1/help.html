Learning tools and help

Make the work readable

  • Use parentheses when substituting negative numbers.
  • Write one mathematical transformation per line.
  • Say what an ordered pair means and label both axes.
  • Use units to check a model; give exact answers before rounding.
  • Read x² as x squared, √a as the principal square root of a, and ≤ as less than or equal to.

If you are stuck

  • Name the known quantities and the quantity requested.
  • Try a small input or substitute a proposed solution.
  • Compare your work with the model one step at a time.
  • Describe the first step you do not understand when requesting help.

Access

The preview supports keyboard navigation and browser zoom. Explanations use selectable text, and plotted examples include descriptions. No task requires color recognition, sound, or dragging. After Canvas import, the instructor should check screen-reader reading order, mathematical notation, zoom, and assignment submission in Student View.
