Algebra 1 / 5.3 · Write linear equations

5.3 · Write linear equations

Learning target

Construct a linear equation from points or a rate.

Think about the idea

Find a slope first, then use a known point to find the starting value. In y = mx + b, substitute the point coordinates and solve for b. Point-slope form y − y₁ = m(x − x₁) records the same relationship. An input-output table is linear when equal input steps have equal output differences.

Worked example

Write a line through (2, 9) and (5, 18).

  1. Slope = (18 − 9)/(5 − 2) = 3.
  2. Substitute (2, 9): 9 = 3(2) + b, so b = 3.
  3. The equation is y = 3x + 3. Both original points satisfy it.

Spot and repair an error

A learner assumes the first point’s output is always b.

Before revealing the explanation, identify the first incorrect step and propose a repair.

Compare your repair

The value b is the output at x = 0, not at whichever input is listed first.

Your turn

Work each question independently. Include a method or explanation, then compare your reasoning.

Practice 1

Write a line with slope 2 through (3, 11).

Check the reasoning

y = 2x + 5, since 11 = 6 + b.

Practice 2

Write a line through (0, 4) and (2, 10).

Check the reasoning

y = 3x + 4; slope is 6/2 = 3.

Practice 3

Outputs are 5, 9, 13 at inputs 1, 2, 3. Find the rule.

Check the reasoning

y = 4x + 1: outputs increase by 4, and 5 = 4(1) + 1.

Reflect before moving on

Explain one decision you made and how you checked it. If your answer changed after checking, record the original error and your corrected reasoning.
