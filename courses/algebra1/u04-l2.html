Algebra 1 / 4.2 · Use function notation

4.2 · Use function notation

Learning target

Evaluate and interpret f(x) in context.

Think about the idea

The notation f(x) names the output of function f at input x. It is not f multiplied by x. Substitute the requested input into the rule. An equation such as f(x) = 10 asks for an input whose output is 10, which is different from evaluating f(10).

Worked example

Let f(x) = 3x − 2. Find f(4), then solve f(x) = 10.

  1. f(4) = 3(4) − 2 = 10.
  2. For f(x) = 10, solve 3x − 2 = 10.
  3. The input is x = 4. The output is 10.

Spot and repair an error

A learner treats f(4) as 4f.

Before revealing the explanation, identify the first incorrect step and propose a repair.

Compare your repair

The parentheses identify the input. Replace x with 4 in the function rule.

Your turn

Work each question independently. Include a method or explanation, then compare your reasoning.

Practice 1

For g(t) = 2t + 5, find g(3).

Check the reasoning

11: 2(3) + 5.

Practice 2

For g(t) = 2t + 5, solve g(t) = 17.

Check the reasoning

t = 6, because 2t + 5 = 17.

Practice 3

A(t) is liters remaining after t minutes. Interpret A(4) = 12.

Check the reasoning

After 4 minutes, 12 liters remain; 4 is time and 12 is volume.

Reflect before moving on

Explain one decision you made and how you checked it. If your answer changed after checking, record the original error and your corrected reasoning.
