Unit 4 self-check · Functions and representations

This is a self-check. Write your reasoning before choosing an answer. Feedback appears after checking; this public preview does not save grades.

1. Which relation is not a function?

Input 1 is paired with both 2 and 3.

2. If f(x) = 4x + 1, what is f(−2)?

4(−2) + 1 = −8 + 1 = −7.

3. A shop sells up to 20 whole notebooks. What is a reasonable sales-count domain?

The count is discrete and capacity bounds it.

4. Find average rate of change from (2, 5) to (6, 17).

(17 − 5)/(6 − 2) = 12/4 = 3.

5. If h(t) is height in meters, what does h(3) = 8 mean?

Function notation pairs the input time 3 with output height 8.
