Algebra readiness self-check

This is a self-check. Write your reasoning before choosing an answer. Feedback appears after checking; this public preview does not save grades.

1. Evaluate −3 + 8.

Starting at −3 and moving 8 units right reaches 5.

2. Compute 3/4 + 1/2.

Use denominator 4: 3/4 + 2/4 = 5/4.

3. What is 20% of 60?

0.20 × 60 = 12.

4. Simplify 3(x + 2).

Distribute the 3 to both terms.

5. Solve x + 7 = 12.

Subtract 7 from both sides.

6. Which point has x = −2 and y = 3?

Ordered pairs list x first, then y.

7. Which ratio is equivalent to 2:3?

Multiply both entries by 2.

8. Find the area of a rectangle 4 cm by 7 cm.

Area = length × width = 28 square centimeters.
