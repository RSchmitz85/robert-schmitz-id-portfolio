# First string change: observer checklist

Learner: __________________  Observer: __________________  Date: __________
Guitar model: __________________  String type and gauge: __________________

Use with a six-string steel-string acoustic, pin bridge and ordinary tuning posts. Consult the guitar maker for hardware-specific methods. An experienced observer should watch the first attempt; do not infer practical ability from the quiz score.

Mark each item **Independent / Prompted / Not yet**. Record what you actually observed.

| Demonstration | Rating and evidence |
|---|---|
| Identifies the guitar design and checks the recommended string type and gauge. | |
| Protects the finish, supports the instrument and prepares appropriate tools. | |
| Releases tension fully before removal; controls and contains sharp wire. | |
| Removes the string and pin gently; stops for persistent resistance. | |
| Identifies the correct replacement and checks ball-end seating at the bridge plate. | |
| Routes the string over the saddle and through the correct nut slot to its post. | |
| Uses the maker's slack, winding and trimming method; leaves controlled wraps. | |
| Tunes gradually to the correct string and octave, checking the tuner reading. | |
| Inspects the pin, routing and wraps; plays gently and retunes. | |
| Explains and follows stop conditions: rising pin, unusual resistance, suspected damage or uncertain pitch. | |

**Pause rule:** the observer intervenes for unsafe force, incorrect string selection or uncertain pitch. Mark the affected step Not yet and practise it again with guidance.

**Readiness decision:** Ready for another observed string / Needs guided practice first.
