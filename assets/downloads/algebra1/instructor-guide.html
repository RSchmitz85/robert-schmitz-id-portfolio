Import into a new empty course

  1. Use a Canvas account that permits course creation and content import. Instructure offers individual access through Canvas Lite; confirm the current features for your account.
  2. Create an empty Algebra 1 course; keep it unpublished during review.
  3. Open Settings → Import Course Content. Select Common Cartridge 1.x Package, choose algebra1-canvas-course.imscc, and import all content. If your instance directs Canvas-flavored packages to Canvas Course Export Package, use that option.
  4. Review the import job for warnings. Confirm the home page, 12 modules, 40 lessons, 12 quizzes, and 10 assignments. The package marks pages, modules, and assignments unpublished; review the resulting quiz availability too.
  5. If the home page is not selected automatically, mark the imported course home as Front Page and choose Pages Front Page as the course home.
  6. In Student View, inspect internal links, plots, quiz feedback and scoring, and assignment submissions. No dates, enrollment, or secure exam rules are configured.
  7. Set dates, local grade policy, accommodation settings, and visibility. The rubric is embedded in each assignment description; create a native SpeedGrader rubric if desired.
  8. Publish only after the mathematical, accessibility, and import review is complete.

Pacing and instruction

Use 2 weeks for readiness and prerequisite support, 3 weeks per unit (30 weeks), and 4 flexible weeks for review, applications, and synthesis. Each unit has four compact core lessons, so allocate other meetings to worked discussion, additional practice, conferences, and revision. Local standards may require additional topics. Select supplementary tasks after inspecting student work; do not equate reading the pages with mastery.

Suggested lesson routine

  • 5 minutes: prerequisite retrieval and launch.
  • 10–15 minutes: model and discuss the worked example.
  • 10 minutes: analyze the misconception with a partner.
  • 15–20 minutes: independent practice and explanation checks.
  • 5 minutes: exit explanation, teacher observation, and next-step grouping.

Differentiation

  • Support: annotate operations and units; use signed-number or fraction examples before symbolic generalization.
  • Language: preteach input, output, intercept, constraint, and residual with examples and nonexamples.
  • Extension: change a condition, compare methods, or construct a counterexample; do not merely increase the size of the numbers.
  • Formative response: use errors to decide between a short individual conference, a small-group model, and additional independent practice.

Unit 1 · Quantities and expressions

Application task guidance

A(n) = 15 + 4n; B(n) = 7n; n is a nonnegative integer. At n = 3: 27 and 21; at 5: 35 and 35; at 8: 47 and 56. Expect a fixed-versus-variable interpretation, not an unsupported claim that one plan is always cheaper.

Quiz key and explanations

  1. 50 miles/hour — Divide distance by time: 150 ÷ 3 = 50 miles/hour.
  2. 24 — (−4)² − 2(−4) = 16 + 8 = 24.
  3. −6x + 15 — Distribute −3 to both terms, including the negative 5.
  4. 10a + 4 — Combine variable terms to get 10a and constants to get 4.
  5. 18 + 7h — The fixed fee is paid once. Only the hourly rate multiplies h.

Unit 2 · Equations and mathematical arguments

Application task guidance

120 + 8s = 360 gives s = 30. General formula s = (C − 120)/8. A nonnegative whole-number s is required for the context. Values below $120 or values not differing from $120 by a multiple of $8 do not produce a feasible exact group.

Quiz key and explanations

  1. 5 — Add 5 to get 6x = 30, then divide by 6.
  2. 7 — 4x + 4 = 2x + 18 gives 2x = 14, so x = 7.
  3. No solution — Subtracting 5x gives the false statement 2 = 8.
  4. C/(2π) — Divide both sides by the nonzero constant 2π.
  5. 3 is incorrect because 2(3) + 9 = 15 — A solution must make the original equality true; 15 does not equal 17.

Unit 3 · Inequalities and constraints

Application task guidance

200 + 12n ≤ 500 and n ≥ 10; hence 10 ≤ n ≤ 25, with n an integer. At n = 25 the cost is exactly $500; n = 26 costs $512.

Quiz key and explanations

  1. 0 and 2 — Both 0 and 2 are greater than −1; the boundary itself is excluded.
  2. x ≤ −4 — Subtract 3, then divide by −2 and reverse the inequality.
  3. −3 ≤ x < 5 — Subtract 4 from all three parts, keeping each boundary type.
  4. 3 — 5 + 8n ≤ 35 gives n ≤ 3.75. Four items would cost $37.
  5. Two regions: at or below 2, or above 6 — Or combines both regions; 2 is included, 6 is excluded.

Unit 4 · Functions and representations

Application task guidance

C(n) = 3n with integer 0 ≤ n ≤ 12; range {0,3,6,…,36}. Points are discrete; a continuous segment would imply fractional notebooks. Accept any accurate five inputs including zero.

Quiz key and explanations

  1. {(1,2),(1,3)} — Input 1 is paired with both 2 and 3.
  2. −7 — 4(−2) + 1 = −8 + 1 = −7.
  3. Integers from 0 through 20 — The count is discrete and capacity bounds it.
  4. 3 — (17 − 5)/(6 − 2) = 12/4 = 3.
  5. Height is 8 meters at 3 seconds — Function notation pairs the input time 3 with output height 8.

Unit 5 · Linear relationships and models

Application task guidance

A outputs 12,24,36,48,60; B outputs 0,18,36,54,72. At 3 hours: A=30, B=27; at 7: A=54, B=63. Break-even h=4. Continuous graphs assume prorated hourly billing; discrete billing requires a different domain or rule.

Quiz key and explanations

  1. −2 — (2 − 8)/(4 − 1) = −6/3 = −2.
  2. (0,7) — Set x = 0 to get y = 7.
  3. y = −2x + 7 — 1 = −2(3) + b gives b = 7.
  4. 9 minutes — Set 0 = 45 − 5t and solve t = 9.
  5. (4,−2) — At x = 4 the output is 2 − 4 = −2.

Unit 6 · Systems and shared solutions

Application task guidance

s+d=40 and 4s+7d=205. Substitute s=40−d: 160+3d=205, so d=15 and s=25. Intersection (25,15) when axes are s and d. Both counts are nonnegative integers.

Quiz key and explanations

  1. (4,12) — x + 3x = 16 gives x = 4 and y = 12.
  2. (6,3) — Adding yields 2x = 12, then y = 3.
  3. Infinitely many solutions — Divide the second equation by 2 to obtain the first.
  4. (1,3) — (1,3) satisfies 4 ≤ 5 and 3 ≥ 1. Each other point violates a constraint.
  5. 2 — Let b count $7 tickets: 4(6−b)+7b=30, so 3b=6 and b=2.

Unit 7 · Exponents and exponential change

Application task guidance

A(t)=100+15t; B(t)=100(1.10)ᵗ. A: 100,115,130,145,160,175,190. B rounded to cents: 100,110,121,133.10,146.41,161.05,177.16. A is larger at month 6. Values are stipulated for a mathematical simulation, not promised real-world returns.

Quiz key and explanations

  1. x⁷ — Multiplying powers with the same base adds the exponents.
  2. 1/9 — 3⁻² = 1/(3²) = 1/9.
  3. 7√2 — 98 = 49 × 2; the principal root is 7√2.
  4. $441 — 400(1.05)² = 400(1.1025) = 441.
  5. 2·3^(n−1) — The first term is 2 and each next term is three times the previous.

Unit 8 · Polynomials and factoring

Application task guidance

Area=(x+2)(x+5)=x²+7x+10 square meters. At x=3 dimensions are 5 by 8 and area 40. Partial products x²,5x,2x,10 expose omitted side strips. A design choice x≥0 guarantees positive dimensions; mathematically x>−2 suffices for both dimensions positive.

Quiz key and explanations

  1. x² + 4x − 2 — Reverse every sign in the subtracted polynomial, then combine.
  2. x² + 4x − 12 — The products give x² + 6x − 2x − 12.
  3. 4(x − 3)(x + 3) — Remove 4, then factor x² − 9 as a difference of squares.
  4. (x+5)(x−3) — 5 + (−3) = 2 and 5(−3) = −15.
  5. x² + 8x + 16 — Both middle products are 4x, giving 8x in total.

Unit 9 · Quadratics and nonlinear models

Application task guidance

Standard −2t²+8t; factored −2t(t−4); vertex −2(t−2)²+8. Launch 0 meters; maximum 8 meters at 2 seconds; landing at 4 seconds. Domain [0,4], range [0,8]. Negative heights after landing are outside the modeled airborne motion.

Quiz key and explanations

  1. (4,2) — The squared term is zero at x=4; the minimum output is 2.
  2. x=2 or 5 — (x−2)(x−5)=0 gives 2 and 5.
  3. x=1 or −5 — x+2=±3 gives x=1 or −5.
  4. One — The discriminant is 16−16=0; (x−2)²=0 has one distinct root.
  5. 6 seconds — Factor −2t(t−6)=0. The positive return time is 6 seconds.

Unit 10 · Data, evidence, and modeling

Application task guidance

Responses vary. Require six labeled pairs, labeled axes, a stated line, correct observed-minus-predicted residuals, meaningful units, and a limitation such as small sample, omitted variables, bounded score, or extrapolation. Do not require fabricated learner gains. Simulation must be labeled.

Quiz key and explanations

  1. 5 — The sum is 20, divided by four observations gives 5.
  2. 60% — 15/25 = 0.60 = 60%.
  3. −4 — Residual = observed − predicted = 14−18 = −4.
  4. Quadratic — First differences 3,5,7 have constant second difference 2.
  5. An observed relationship, with causation still unproven — Association alone cannot distinguish causation from confounding or other explanations.

Readiness check

  1. 5 — Starting at −3 and moving 8 units right reaches 5.
  2. 5/4 — Use denominator 4: 3/4 + 2/4 = 5/4.
  3. 12 — 0.20 × 60 = 12.
  4. 3x + 6 — Distribute the 3 to both terms.
  5. 5 — Subtract 7 from both sides.
  6. (−2,3) — Ordered pairs list x first, then y.
  7. 4:6 — Multiply both entries by 2.
  8. 28 cm² — Area = length × width = 28 square centimeters.

Cumulative check

  1. $35 — 11 + 6(4) = 35.
  2. 8 — 3x−3=2x+5 gives x=8.
  3. x > −4 — Divide by −5 and reverse direction.
  4. 10 — (−3)²+1=9+1=10.
  5. y=4x−5 — 3=4(2)+b gives b=−5.
  6. (8,3) — Adding gives 2x=16, then y=3.
  7. 250(0.92)ᵗ — A decline of 8% retains 92% per year.
  8. (x−4)(x−5) — −4 and −5 sum to −9 and multiply to 20.
  9. x=1 or 5 — (x−1)(x−5)=0, so x=1 or 5.
  10. 5 — Observed minus predicted: 47−42=5 points.
